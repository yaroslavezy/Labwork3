# Brace Space Checker (Надточий Ярослава м3119)

Плагин для **Visual Studio Code**, который проверяет правило стиля кода: между закрывающей круглой скобкой `)` и открывающей фигурной скобкой `{` должен стоять ровно один пробел.


## Возможности

- **Подсветка нарушений.** Места вида `if (x){` подчёркиваются предупреждением и попадают в панель «Проблемы».
- **Быстрое исправление** (`Ctrl+.` или лампочка): один клик ставит пробел; есть вариант «исправить все нарушения в файле».
- **Три вида нарушений:** пробела нет (`){`), пробелов или табуляции слишком много (`)   {`, `)	{`), пробел запрещён правилом (режим `forbid`).
- **Умный разбор текста.** Содержимое строк, символьных литералов, комментариев (`//`, `/* */`) и сырых строк C++ (`R"x(...)x"`) игнорируется, поэтому ложных срабатываний на `"){"` нет. Разделители разрядов C++14 (`1'000'000`) не принимаются за кавычки.
- **Стиль Олмана не считается нарушением:** если `{` стоит на отдельной строке, плагин молчит.
- **Строка состояния:** число нарушений в текущем файле, по клику открывается отчёт.
- **Команды** (палитра команд `Ctrl+Shift+P`):
  - `Brace Space: исправить все нарушения в файле`;
  - `Brace Space: показать отчёт по текущему файлу` (всего нарушений, по видам, по строкам);
  - `Brace Space: проверить весь проект` (сводка по всем файлам рабочей папки, файлы с наибольшим числом нарушений идут первыми).
- **Настройки** (`settings.json`):

| Параметр | По умолчанию | Описание |
|---|---|---|
| `braceSpace.mode` | `require` | `require` — ровно один пробел, `forbid` — пробелов нет |
| `braceSpace.languages` | `["c","cpp","java"]` | языки, для которых работает проверка |
| `braceSpace.checkOnType` | `true` | проверять при наборе (с задержкой 300 мс) |
| `braceSpace.maxFileSizeKb` | `2048` | файлы больше этого размера пропускаются |
| `braceSpace.workspaceGlob` | `**/*.{c,cc,cpp,cxx,h,hh,hpp,hxx,java}` | маска файлов для проверки проекта |

## Установка и запуск

Нужны [Node.js](https://nodejs.org) 18+ и VS Code 1.80+.

```bash
npm install
npm run compile
npm test            # модульные тесты ядра
```

**Запуск в режиме разработки:** откройте папку проекта в VS Code и нажмите `F5`. Откроется второе окно («Extension Development Host») с папкой `sample/`, где лежат примеры `example.cpp` и `Example.java`.

**Установка как обычного расширения:**

```bash
npm run package     # создаст brace-space-checker-1.0.0.vsix
code --install-extension brace-space-checker-1.0.0.vsix
```

## Структура проекта

```
src/
  extension.ts    точка входа: команды, подписки на события
  diagnostics.ts  запуск проверки, кэш, дебаунс, подчёркивания
  codeActions.ts  быстрые исправления
  config.ts       чтение настроек
  checker.ts      ядро: findViolations(), applyFixes()
  scanner.ts      классификация символов: код / комментарий / литерал
  lineIndex.ts    смещение → строка и столбец (двоичный поиск)
  stats.ts        сводка и текстовый отчёт
  types.ts        общие типы
sample/           файлы для ручной проверки
docs/             документация
```

Подробное описание модулей, алгоритма и структур данных: [docs/DOCUMENTATION.md](docs/DOCUMENTATION.md).

## Ограничения

- Разбор рассчитан на синтаксис C, C++ и Java. Для языков с другими видами строк (шаблонные строки JavaScript, `@"..."` в C#, Python) возможны ложные срабатывания, поэтому по умолчанию они не включены.
- Плагин не заменяет форматтер: он находит и исправляет только одно правило.
